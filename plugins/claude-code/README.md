# Obsidian Brain Claude Code Plugin Template

This folder is a scaffold for a future Claude Code plugin bundle. The Public Beta install path remains the CLI plus MCP registration documented in the root README.

Use these files as templates:

- `plugin.template.json` describes the intended bundle metadata.
- `settings.template.json` shows the Claude Code hook shape.
- `CLAUDE.template.md` contains optional user-facing instructions.

Replace every `/absolute/path/to/obsidian-brain-mcp-server` and `/path/to/your/obsidian/vault` placeholder before using the template.
